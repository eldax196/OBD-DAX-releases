# OBD DAX — versiones estables

Este repositorio solo contiene las versiones **estables** de la app OBD DAX (APK para Android).
La app las consulta desde *Ajustes → Actualizaciones*; las versiones de prueba no se publican aquí.

Cada release incluye el APK y la lista de cambios. La línea `versionCode: N` de la descripción la usa la app para comparar versiones.
